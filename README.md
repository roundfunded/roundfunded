# Round Funded

Round Funded matches founders to investors from a 60,000+ investor database and gives you a fundraising data room for the close. Fundraising is super easy. Start with [investor match](https://roundfunded.com/en/tools/investor-match).

Last updated: 2026-08-14

## Who this is for

Founders raising pre-seed through Series C who need a vetted list of angels and VCs, a match by stage, industry, and country, and a data room. This is the problem: finding the right investors is slow and noisy. Round Funded is the matching product and the data room, not a person doing outbound for you.
